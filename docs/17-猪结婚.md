# 猪结婚（/waifu、/每天日尊挑战）

> 适用：v0.9.0 之后新增的独立功能 ｜ 每天每群形成互不重叠的配对
>
> 群友发 `/waifu` 或 `/每天日尊挑战`，机器人把发送者头像和随机选中的群友头像
> 拼进「猪结婚」模板，以引用回复的形式发回，并附带文字「你今天的老婆是 xxx」。

## 1. 触发

| 命令 | 说明 |
| --- | --- |
| `/waifu` | 不区分大小写，支持全角斜杠 |
| `/每天日尊挑战` | 与 `/waifu` 完全等价 |

只认**整条消息恰好是命令**；`/waifu 123`、`waifu`（不带斜杠）不触发。
只处理群消息，私聊无效；不依赖 `CHAT_ENABLED` / `CHAT_GROUPS`，
但必须在 `.env` 的 `FUN_GROUPS` 白名单内（为空则功能关闭）。

## 2. 配对规则

每天每群维护一组互不重叠的配对，按 UTC+8 自然日重置：

1. A 发命令，A 当天还没配对：从当前群“未配对、非机器人、不是 A 自己”的成员里随机选 B；
   A-B 成对；拼图（A 左、B 右）；回复 A：`你今天的老婆是B的群昵称`。
2. A 当天再发：已经和 B 配对，直接返回 B 和第一次拼好的图，不再随机。
3. B 当天发：查到 B 已和 A 配对，直接返回 A；文字变成 `你今天的老婆是A的群昵称`；
   图片沿用第一次那张（A 左、B 右）。
4. C 当天发：A、B 都已配对，**不能选 A 或 B**；从剩余未配对成员里随机选 D；C-D 成对。
5. 未配对的人发命令，但群里没有其他未配对成员：回复“群里没有其他群友可选”，不生成图片。

其他约定：

- **群昵称**优先取群名片 `card`，没有就用 QQ 昵称 `nickname`，再没有就用 QQ 号。
- 排除发送者本人、机器人自己、其他已知机器人（`CHAT_IGNORE_QQ`）和当天已配对成员。
- 配对按群隔离：A、B 在群 1 配对，不影响他们在群 2 的结果。
- 输出约 100–160 KB JPEG，低于 OneBot 单帧限制。

## 3. 拼图

模板：`assets/memes/waifu/猪结婚.jpg`（1012×1024）。

| 位置 | 白色区域 | 尺寸 | 放谁 |
| --- | --- | --- | --- |
| 左边 | x 239→504，y 309→627 | 265×318 | 发送者头像 |
| 右边 | x 534→817，y 346→623 | 283×277 | 被选中群友头像 |

头像用 `cover` 方式裁切填满白块：不变形、不留白边，头像两侧可能被裁掉一点。
`猪结婚 - 要求.jpg` 只是说明图，运行时不用。

换模板时必须同步修改 `deltaforce_bot/render/waifu_card.py` 里的
`TEMPLATE_SIZE`、`SENDER_BOX`、`TARGET_BOX`，否则启动会报模板尺寸不匹配。

## 4. 存储

独立 SQLite：`data/waifu.sqlite3`，不复用聊天/每日密码数据库。

- `waifu_pairs`：一对一行，存拼好的 JPEG（BLOB）；
- `waifu_members`：每个成员一行（A→B、B→A），主键 `(day, group_id, user_id)`
  保证同一天同一个群里一个人只能出现在一对里；
- 只保留今天和昨天（`WAIFU_KEEP_DAYS=2`），启动时清理更早的记录；
- 重启后当天配对仍然有效，不会重新抽。

## 5. 配置

```dotenv
FUN_GROUPS=1071781482,1130331921
WAIFU_ENABLED=true
WAIFU_DB_PATH=data/waifu.sqlite3
WAIFU_TEMPLATE=assets/memes/waifu/猪结婚.jpg
WAIFU_KEEP_DAYS=2
WAIFU_AVATAR_TIMEOUT=10
WAIFU_AVATAR_MAX_BYTES=5242880
WAIFU_MAX_ATTEMPTS=3
```

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `FUN_GROUPS` | 空 | 娱乐功能开放群；为空时猪结婚关闭 |
| `WAIFU_ENABLED` | `true` | 功能开关 |
| `WAIFU_DB_PATH` | `data/waifu.sqlite3` | 配对/图片 SQLite |
| `WAIFU_TEMPLATE` | `assets/memes/waifu/猪结婚.jpg` | 拼图模板 |
| `WAIFU_KEEP_DAYS` | `2` | 保留天数（含今天） |
| `WAIFU_AVATAR_TIMEOUT` | `10` | 头像请求超时秒数 |
| `WAIFU_AVATAR_MAX_BYTES` | `5242880` | 单张头像上限 |
| `WAIFU_MAX_ATTEMPTS` | `3` | 头像失败时最多尝试几个候选 |

改 `.env` 后需要重启 `deltaforce-bot`。

## 6. 部署

本功能新增了 Pillow 依赖（拼图用），部署时**不能**加 `--skip-deps`，
否则服务器没有 Pillow，功能会降级为不可用（不会拖垮其他插件）。

```powershell
.\.venv\Scripts\python.exe .\scripts\deploy_server.py --host 39.106.135.148 --user root `
  --skip-assets
```

模板图片不在 Git 里，需要单独上传：

```powershell
scp -r .\assets\memes\waifu root@39.106.135.148:/opt/deltaforce-qqbot/assets/memes/
```

服务器确认：


## 7. 验收

1. A 发 `/waifu` → 回一张拼图，文字是 B 的群昵称；A 再发 → 同一个人、同一张图。
2. B 发 `/waifu` → 文字变成 A 的群昵称，图片和 A 收到的一样（A 左 B 右）。
3. C 发 `/waifu` → 不会选中 A 或 B，只能从剩余未配对成员里选。
4. 同一天重复上述操作，配对关系不变；第二天重新配对。
5. 只有发送者和机器人、没有其他可选成员时，回复“群里没有其他群友可选”。
6. 关闭聊天（`CHAT_ENABLED=false`）后命令仍然可用。

## 9. 常见问题

**发命令没反应？**
看启动日志有没有“猪结婚已启用”。没有的话检查 `WAIFU_ENABLED`、模板路径、Pillow 是否安装。

**提示“群里没有其他群友可选”？**
当天群里除了发送者/机器人，其他人都已经配对了；换个人或等第二天重置。

**B 收到的图片为什么左右和自己是反的？**
B 和 A 共享同一张配对图（A 左、B 右），这是“共享缓存”的预期行为，不重新拼图。

**能选机器人吗？**
不能。机器人自己、`CHAT_IGNORE_QQ` 里的账号和其他标记为机器人的成员都会被排除。

**换模板后报尺寸错误？**
模板必须是 1012×1024；换图后要同步修改 `SENDER_BOX` / `TARGET_BOX` 坐标。
