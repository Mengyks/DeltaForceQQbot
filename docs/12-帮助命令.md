## 1. 命令

```
/帮助
/帮助命令
/help
/功能
```

- 必须带 `/` 或全角 `／` 前缀；聊天插件已把它识别为命令，不会交给 LLM。
- 群内所有人可用；不限制群。
- 不请求任何外部接口，不消耗数据帝资源。

## 3. 渲染与缓存

- 复用 `CardRenderer`，视口宽 1000px；
- JPEG 质量阶梯 86→80→72→64，目标 350 KB，硬上限 600 KB；
- 实测预览约 **205 KB**；
- 卡片是静态内容：发送成功后缓存 **24 小时**（模块级 `TTLCache`，key `help-v4`）；
- 渲染失败或发图失败自动回退同内容的文字版；
- 背景图缺失时使用紫/粉渐变兜底，不会导致整张卡片失败。

预览脚本：

```bash
.venv/Scripts/python.exe scripts/render_help_preview.py
# → assets/_preview/help_preview.jpg
```

## 6. 验收

1. 群里发 `/帮助` → 收到带背景的帮助图片。
2. 检查标题、九个功能块、指令和示例是否完整。
3. 再次发送 → 命中 24 小时图片缓存，不再渲染。
4. 背景文件缺失/渲染失败 → 自动回退文字帮助。
5. 卡战备、每日密码、制造利润、直播订阅测试保持通过。

## 7. 已知限制

- 帮助内容是静态的，功能变化时需要同步修改 `services/help.py`；
  图片缓存 key 目前是 `help-v4`，内容大改时建议继续递增以免进程内旧缓存。
- 背景图属于图片资源，不入 Git；换机器/重装需要重新上传。
- 卡片较高（1000×1450），QQ 内需要滚动查看，但信息密度完整。
- 文字兜底会较长，适合在图片发送失败时保底。
