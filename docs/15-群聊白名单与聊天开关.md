# 群聊白名单与聊天开关

> 适用：当前 v0.9.0 ｜ 涉及 `.env`：`CHAT_ENABLED`、`CHAT_GROUPS`、`DEBUG_GROUPS`
>
> 目标：把指定 QQ 群加入/移出聊天白名单，以及全局开启/关闭群聊功能。
> **注意：`CHAT_GROUPS` 不只影响聊天，也影响每日密码推送和直播命令可用群；
> 直播推送只发给实际订阅了该主播的群。**

## 1. 先理解两个配置

| 变量 | 作用 |
| --- | --- |
| `CHAT_ENABLED` | 群聊总开关。`false` 时聊天服务完全不创建，@/引用/跟进窗口都不会回复 |
| `CHAT_GROUPS` | 聊天白名单群；**同时**是每日密码默认推送群和直播命令可用群 |
| `DEBUG_GROUPS` | 可选，白名单内免限流（卡战备、聊天、直播等共用） |
| `FUN_GROUPS` | 娱乐功能白名单：猪猪表情包、猪结婚、每日天尊挑战；为空则三个功能全部关闭 |

当前生产值（示意）：

```dotenv
CHAT_ENABLED=true
CHAT_GROUPS=1071781482,1130331921
DEBUG_GROUPS=1071781482,1130331921
FUN_GROUPS=1071781482,1130331921
```

支持英文逗号、中文逗号、空格；只解析数字群号。

## 2. 各功能如何使用 `CHAT_GROUPS`

| 功能 | 是否受 `CHAT_GROUPS` 影响 |
| --- | --- |
| 群聊（@/引用/别名/跟进） | 是；必须 `CHAT_ENABLED=true` 且群在列表里 |
| 每日密码定时推送 | 是；`DAILY_PASSWORD_GROUPS` 为空时沿用 `CHAT_GROUPS` |
| 每日密码手动查询 | 否；任何群发 `/每日密码` 都可以 |
| 直播订阅推送 | 间接：命令只能在 `CHAT_GROUPS` 群使用；推送只发给实际订阅了该主播的群 |
| 直播订阅命令 | 是；只能在 `CHAT_GROUPS` 的群里使用 |
| 卡战备 | 否；任何群可用 |
| 制造利润 | 否；任何群可用 |
| 帮助 | 否；任何群可用 |
| 猪猪表情包 | 否；受 `FUN_GROUPS` 控制（精确触发词，同群 5 秒冷却） |
| 猪结婚 | 否；受 `FUN_GROUPS` 控制（`/waifu`、`/每天日尊挑战`，配对按群/天隔离） |
| 每日天尊挑战 | 否；受 `FUN_GROUPS` 控制（`/每日天尊挑战`，缓存按群/人/天隔离） |
| 上下文清理 | 是；需要聊天服务存在，且群在 `CHAT_GROUPS` |

> `FUN_GROUPS` 与 `CHAT_GROUPS` 完全独立：聊天关掉不影响娱乐功能，娱乐功能关掉也不影响聊天；
> 但娱乐功能只会在 `FUN_GROUPS` 列出的群里响应。

> 所以：**不要为了“只关某个群的聊天”直接把它从 `CHAT_GROUPS` 删掉**，
> 否则它也会失去每日密码推送和直播命令权限；该群已有的直播订阅会暂停推送，
> 重新加入 `CHAT_GROUPS` 后恢复。

### 2.1 娱乐功能白名单 `FUN_GROUPS`

猪猪表情包、猪结婚、每日天尊挑战不依赖聊天，但统一受 `FUN_GROUPS` 控制：

```dotenv
FUN_GROUPS=1071781482,1130331921
```

- 与 `CHAT_GROUPS` 完全独立：关聊天不影响娱乐功能，关娱乐功能也不影响聊天；
- **为空 = 三个功能全部关闭**；
- 支持英文逗号、中文逗号、空格；只解析数字群号；
- 修改后必须重启 `deltaforce-bot`。

## 3. 把指定群加入白名单

### 3.1 先确认 bot 已在群里

白名单只是配置，前提是机器人 QQ 已经在目标群中。先邀请机器人进群。

群号可以在 QQ 群设置里看到，也可以在 bot 日志中看到：

```
[群:123456789]
```

### 3.2 修改服务器 `.env`

登录服务器：

```bash
ssh root@39.106.135.148
cd /opt/deltaforce-qqbot
```

先备份：

```bash
cp -a .env ".env.bak-chat-$(date +%Y%m%d-%H%M%S)"
```

编辑 `.env`（用 `vim`/`nano` 均可），把新群号追加到 `CHAT_GROUPS`：

```dotenv
CHAT_ENABLED=true
CHAT_GROUPS=1071781482,1130331921,123456789
```

如果希望新群也免限流（测试群可以，正式群慎用）：

```dotenv
DEBUG_GROUPS=1071781482,1130331921,123456789
```

保存后确认（只 grep 非敏感项）：

```bash
grep -E '^(CHAT_ENABLED|CHAT_GROUPS|DEBUG_GROUPS|DAILY_PASSWORD_GROUPS)=' .env
```

### 3.3 重启 bot

`.env` 只在进程启动时读取，**必须重启**：

```bash
systemctl restart deltaforce-bot
sleep 3
systemctl status deltaforce-bot --no-pager
journalctl -u deltaforce-bot -n 60 --no-pager
```

预期日志：

```
群聊机器人已启用：3 个群，模型 deepseek-flash
```

如果日志是“群聊机器人已启用：2 个群”，说明 `.env` 没生效或改错行。

### 3.4 群内验证

- 在新群 `@机器人` 发一句话 → 应回复；
- 直接回复机器人消息 → 应进入跟进窗口；
- 在另一个群发 `/卡战备 巴克什 绝密` → 仍应正常（卡战备不受影响）。

## 4. 开启 / 关闭聊天

### 4.1 全局关闭聊天（保留其他功能）

```dotenv
CHAT_ENABLED=false
```

重启 `deltaforce-bot`。

效果：

- 不再处理任何群聊 @/引用/别名/跟进；
- 不调用 LLM，不产生聊天 token 费用；
- 聊天记录仍在 `data/chat.sqlite3`，不会自动删除；
- 卡战备、每日密码、直播订阅、制造利润、帮助**不受影响**；
- 上下文清理不可用（聊天服务未创建）。

验证：

```bash
journalctl -u deltaforce-bot -n 60 --no-pager | grep -E '群聊机器人|CHAT'
```

`CHAT_ENABLED=false` 时通常不会出现“群聊机器人已启用”日志。
群里 @机器人 不应回复；发 `/帮助` 应仍然回复。

### 4.2 全局开启聊天

```dotenv
CHAT_ENABLED=true
CHAT_GROUPS=1071781482,1130331921
```

重启后日志出现：

```
群聊机器人已启用：2 个群，模型 deepseek-flash
```

### 4.3 只关闭某个群的聊天

当前代码**没有“按群单独关闭聊天”的开关**：

- `CHAT_ENABLED` 是全局的；
- `CHAT_GROUPS` 是白名单；
- 直播/每日密码又复用 `CHAT_GROUPS`。

所以可选方案只有：

| 需求 | 做法 |
| --- | --- |
| 只关某个群的聊天，其他群正常 | 当前不支持；需要改代码增加“聊天排除群”或独立 `LIVE_GROUPS`/`DAILY_PASSWORD_GROUPS` |
| 该群不需要每日密码/直播 | 从 `CHAT_GROUPS` 删除该群即可 |
| 该群仍要每日密码，但不需要聊天 | 当前无法同时满足；只能全局关聊天，或用 `DAILY_PASSWORD_GROUPS` + 独立直播组（需改代码） |

> 如果以后需要“聊天白名单”和“推送白名单”分离，可以新增 `LIVE_GROUPS` 和
> `CHAT_EXCLUDE_GROUPS`，但当前版本没有。

## 5. 从白名单移除群

```dotenv
CHAT_GROUPS=1071781482,1130331921
```

重启 bot。

会产生这些副作用：

1. 该群不再聊天；
2. 如果 `DAILY_PASSWORD_GROUPS` 为空，该群不再收到 11:00 每日密码推送；
3. 该群已有的直播订阅暂停推送（订阅记录保留），也不能使用 `/直播订阅` 命令；
4. 卡战备、制造利润、帮助仍然可用；
5. 猪猪表情包、猪结婚、每日天尊挑战只看 `FUN_GROUPS`，不受 `CHAT_GROUPS` 变化影响。

如果只是想让该群不聊天、但仍要每日密码推送，设置独立的推送群：

```dotenv
DAILY_PASSWORD_GROUPS=1071781482,1130331921,123456789
CHAT_GROUPS=1071781482,1130331921
```

但直播命令可用群和推送范围仍分别跟随 `CHAT_GROUPS` / 实际订阅群。

## 6. 常见问题

### 6.1 改了 `.env` 但没生效

- 是否 `systemctl restart deltaforce-bot`？
- 是否改的是服务器 `/opt/deltaforce-qqbot/.env`，不是本地？
- 是否用了 `--upload-env` 把本地 `.env` 覆盖了服务器？部署脚本默认保留服务器 `.env`，
  只有显式 `--upload-env` 才覆盖。
- 群号是否是纯数字、用英文/中文逗号分隔？

### 6.2 `CHAT_ENABLED=true` 但聊天没反应

检查：

```dotenv
CHAT_ENABLED=true
CHAT_GROUPS=...包含该群...
LLM_API_KEY=（已配置）
LLM_MODEL=deepseek-flash
```

启动日志应出现“群聊机器人已启用”。如果出现：

```
CHAT_ENABLED=true，但聊天未就绪（检查 CHAT_GROUPS / LLM_API_KEY / LLM_MODEL）
```

说明群列表为空或 LLM 配置缺失。

如果希望群友不 @ 也能用名字触发，配置 `CHAT_ALIASES`（全局生效，不是按群）：

```dotenv
CHAT_ALIASES=五点,小五点
```

### 6.3 关闭聊天后上下文清理还能用吗

不能。`CHAT_ENABLED=false` 时 Runtime 不创建聊天服务，清理 matcher 不会生效。
需要清理聊天记录时：

1. 临时设 `CHAT_ENABLED=true`，重启；
2. 用 `SUPERUSERS` 执行 `@机器人 上下文清理 直接清理`；
3. 再关闭。

或者直接停 bot 后操作 `data/chat.sqlite3`（需谨慎，建议先备份）。

### 6.4 加入白名单后收到每日密码/直播推送

- 每日密码：`CHAT_GROUPS` 仍是默认推送群；不想收就设置 `DAILY_PASSWORD_GROUPS`
  明确列出需要的群。
- 直播：订阅是**按群**的，只有本群实际订阅过的 UID 才会推送；A 群订阅不会广播到 B/C 群。
- 移除群后，该群已有直播订阅会暂停（记录保留）；重新加入 `CHAT_GROUPS` 后恢复。

### 6.5 `DEBUG_GROUPS` 要不要加

`DEBUG_GROUPS` 内的群会绕过卡战备/聊天/直播的限流。建议只给测试群加；
正式群加入后用户刷屏可能导致更多请求/费用。
