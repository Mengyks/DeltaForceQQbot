## 1. 已实现功能

### 1.1 卡战备（V1，未改动）

`/卡战备 <地图> <难度> [兑换]`，图片卡片；缓存 4 小时；数据源额度保护。
具体字段语义、档位表、部署历史见 `docs/05` 和 `docs/02`。

### 1.2 群聊机器人（V2）

- **只开群聊**，私聊不进入聊天。
- **群白名单** `CHAT_GROUPS`；目前两个测试/主群。
- **立即触发**：任意位置 @机器人、引用机器人消息、文本包含 `CHAT_ALIASES`。
- **跟进窗口**：机器人成功回复后 180 秒；窗口内所有人类群消息可触发；最多再回 3 次，
  两次至少间隔 20 秒；窗口按群独立。
- **主动参与 ambient**：当前 `CHAT_AMBIENT_ENABLED=false`（关闭）。需要更话痨时可打开。
- **群共享上下文**：写入 `data/chat.sqlite3`，默认保留 7 天；不是只记录被 @ 的消息。
- **短句独立消息**：模型输出的多句按换行/句末标点拆成最多 3 条独立 QQ 消息逐条发送；
  不使用 QQ 的“引用回复”，避免看起来回错人。
- **当前消息图片**：`image`/`mface` 会下载后作为 `image_url` 给模型做视觉理解；历史图片只存 `[图片]`。
- **本地表情包**：模型通过 `send_meme(category)` 工具从 `assets/memes` 选图；同群 30 秒冷却、
  10 分钟最多 5 张、避开最近 8 张；只发本地图，不做网页图片搜索。
- **上下文清理**：`@机器人 上下文清理 提取摘要` / `@机器人 上下文清理 直接清理`，
  **只有 `SUPERUSERS` 可用**；群主/管理员无权。

## 2. 代码结构（V2 新增部分）

```
plugins/llm_chat.py                 # 群聊入口：event_preprocessor 记录、聊天 matcher、清理指令
deltaforce_bot/adapters/llm.py      # OpenAI 兼容客户端（tools/tool_calls、重试、usage）
deltaforce_bot/adapters/chat_memory.py  # SQLite 消息/摘要/token 用量
deltaforce_bot/adapters/memes.py    # 本地表情包索引（manifest + memes/）
deltaforce_bot/models/chat.py       # ChatIncoming/ChatReply/StoredMessage/SummaryResult
deltaforce_bot/services/chat.py     # 触发/窗口/上下文/人设/图片/工具循环/摘要
config/persona.md                   # 当前 wudian 人格（热加载）
assets/memes/                       # 服务器上的本地表情包（不入库）
docs/06-LLM群聊机器人.md             # 详细配置与验收
```

`Runtime` 在启动时装配 `ChatMemory`、`LLMClient`、`MemeLibrary`、`ChatService` 和聊天限流器；
`Runtime.aclose()` 会关闭 LLM/图片 HTTP 客户端并关闭 SQLite。

关键行为：

- `CHAT_ENABLED=false` 时 Runtime 不创建聊天服务，记录器/matcher 自动 no-op；卡战备不受影响。
- 人格文件按 mtime 自动重载；表情包索引只在服务启动时扫描，**增删表情包后需重启**。
- 模型不支持 `tools` 或工具调用失败时，会退回普通文字聊天（不会发图）。
- 工具调用最多一轮；一次回复最多一张表情包；发送图片失败不会影响文字。

## 6. 已知限制 / 风险

- 模型可能偶尔不按人格要求输出长句；代码只按换行/句末标点拆，不会强行按逗号切。
- 表情包按分类随机，不精确到某张；分类由 manifest/目录决定。
- 表情包索引只在启动时扫描；增删图后必须重启服务。
- 跟进窗口/ambient 冷却/表情包冷却都是内存态；重启后窗口清空，聊天记录仍持久化。
- 模型工具调用可能失败或模型不支持 tools，会退回文字；不会影响卡战备。
- 聊天日志会包含 NoneBot 打印的入群消息（现有行为）；聊天模块自己的日志不打印完整内容。
- 成本：每次聊天/工具调用都消耗 token；`CHAT_DAILY_TOKEN_BUDGET=200000` 是本地熔断，不是供应商账单上限。
- 本地表情包来源是第三方素材（CC0 标注见 manifest），上线前自行确认版权/内容合规。
