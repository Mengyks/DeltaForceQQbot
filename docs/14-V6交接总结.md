## 4. 架构与启动流程

```
QQ 群消息
  → NapCat（OneBot v11）
  → 反向 WebSocket ws://127.0.0.1:8099/onebot/v11/ws
  → NoneBot2
     ├─ plugins/      匹配命令/事件，发送消息，启动定时任务
     ├─ services/     业务逻辑（不依赖 NoneBot，可单测）
     ├─ adapters/     外部数据：HTTP 客户端、SQLite、缓存、额度、限流
     ├─ models/       纯数据模型
     └─ render/       Jinja2 模板 → Playwright 截图
```

启动顺序（`bot.py`）：

1. `nonebot.init()`；
2. 注册 OneBot V11 适配器；
3. 把标准库 logging 接到 loguru；
4. 从 `pyproject.toml` 加载 `plugins/`；
5. 创建 `Runtime` 单例（校验配置、装配客户端/服务/缓存/渲染器）；
6. 安装掉线监控；
7. `nonebot.run()`；关闭时 `Runtime.aclose()` 释放 HTTP/SQLite/浏览器。

### 4.1 分层与优先级

- 插件层只做匹配与发送；业务逻辑在 `services/`；外部数据在 `adapters/`。
- 消息 matcher 优先级：
  - 上下文清理：`priority=9`
  - 卡战备、每日密码、直播订阅、制造利润、帮助：`priority=10`
  - 群聊：`priority=50`
  - 全部 `block=True`
- `plugins/llm_chat.py` 还有 `event_preprocessor`，负责把白名单群的人类消息写入聊天数据库。
- 聊天插件会把 `/卡战备`、`/每日密码`、`/直播订阅`、`/制造利润`、`/帮助`、`上下文清理`
  识别为命令，不会交给 LLM。

### 4.2 定时任务

| 任务 | 位置 | 节奏 |
| --- | --- | --- |
| 每日密码预热 | `plugins/daily_password.py` | 每 20s 检查；00:15~11:00 窗口；失败每 60s 重试，最多 15min |
| 每日密码推送 | 同上 | 每 20s 检查；11:00~12:00 补推窗口；同一天每群只成功一次 |
| 直播轮询 | `plugins/live_watch.py` | 每 180s；批量查所有订阅；失败指数退避（最长 15min） |
| 制造利润 | 无 | 按需查询；12h 缓存 |
| 帮助页 | 无 | 按需渲染；图片缓存 24h |

## 7. 数据源、成本与缓存

### 7.1 数据帝

- 卡战备 V4：`/v1/sjz_api/jzv4_zb`，1 次资源/请求；4h 缓存；5 个档位理论日均 ≤30 次。
- 制造利润 Pro：`/v1/sjz_api/manufacturePro`，1 次资源/台；四台一次 4 次；12h 缓存；
  正常最多 8 次/天、约 240 次/月。
- 凑战备 DIY：10 次资源/请求；`CUSTOM_ENABLED=false`。
- 本地熔断：`ORZICE_DAILY_QUOTA=2000`；实际日均远低于此值。
- token 只在服务端使用，不写日志/缓存键；平台要求所有请求必须缓存。

### 7.2 免费源

## 11. 已知问题 / 风险

1. **QQ 账号被踢/登录失效**：第三方协议端在云服务器 IP 上风控概率高；需要扫码或密码回退；
   详见掉线指南。
2. **NapCat 重启可能要扫码/短信**：不要频繁重启；优先 WebUI 热操作。
3. **服务器与 GitHub 版本差**：部署前确认服务器 `.env`/代码；部署脚本默认保留 `.env`。
4. **数据帝是非官方第三方服务**：可能改字段/停服/限额；契约测试会报警；
   卡战备 4h 缓存、制造利润 12h 缓存都是内存态，重启会重新取数。
5. **制造利润官方数据版不用**：没有 Lv3 参数、价格与 Pro 不一致、平台标注“不准”。
6. **B站直播**：WAF 会拦默认 `python-httpx` UA（412）；已固定浏览器 UA；
   只推开播、不推下播；轮询最坏约 3 分钟延迟；群主/SUPERUSERS 才能增删。
7. **每日密码免费源**：4399/eleven 非官方，可能改版/停服；同一天一旦用备用源，
   当天不会因主源恢复而升级。
8. **资源不入库**：换机/重装要重新上传 `assets/items`、`assets/memes`、`.env`、`data/`。
9. **图片体积**：OneBot 单帧约 1 MB；每日密码卡用 JPEG ~217 KB，帮助页 ~205 KB，
   制造台 ~84 KB，直播 ~58 KB；卡片渲染失败会回退文字。
10. **聊天成本**：`CHAT_DAILY_TOKEN_BUDGET=200000` 是本地熔断，不是供应商账单上限。
11. **上下文清理权限**：只能 `SUPERUSERS`，群主/管理员没有权限。
12. **帮助页是静态内容**：功能变化要改 `services/help.py`；图片缓存 key 目前 `help-v1`，
    大改时建议递增。
13. **`LLM_BASE_URL`**：服务器当前值不带 `/v1`，客户端固定拼 `/chat/completions`；
    官方文档推荐 `/v1`，改动前先验证。
