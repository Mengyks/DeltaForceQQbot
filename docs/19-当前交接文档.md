### 3.1 四个白名单

| 变量 | 作用 |
| --- | --- |
| `CHAT_GROUPS` | 群聊白名单；同时是每日密码默认推送群、直播推送/命令群 |
| `DAILY_PASSWORD_GROUPS` | 每日密码推送群；为空时沿用 `CHAT_GROUPS` |
| `FUN_GROUPS` | 娱乐功能白名单：猪猪表情包、猪结婚、每日天尊挑战；**为空=三个功能全部关闭** |
| `DEBUG_GROUPS` | 调试群；卡战备/聊天/直播等免限流 |

`FUN_GROUPS` 与 `CHAT_GROUPS` 完全独立：关闭聊天不影响娱乐功能，关闭娱乐功能也不影响聊天。
当前服务器 `FUN_GROUPS` 已有三个群，新增群只需追加群号并重启 `deltaforce-bot`。

## 4. 总体架构

```
QQ 群消息
  → NapCat（OneBot v11）
  → 反向 WebSocket ws://127.0.0.1:8099/onebot/v11/ws
  → NoneBot2
     ├─ plugins/      匹配命令/事件，发送消息，启动定时任务
     ├─ services/     业务逻辑（不依赖 NoneBot，可单测）
     ├─ adapters/     外部数据：HTTP 客户端、SQLite、缓存、额度、限流、图库索引
     ├─ models/       纯数据模型
     └─ render/       Jinja2 模板 → Playwright 截图；Pillow 拼图
```

### 4.1 启动流程（`bot.py`）

1. `nonebot.init()`；
2. 注册 OneBot V11 适配器；
3. 把标准库 logging 接到 loguru；
4. 从 `pyproject.toml` 加载 `plugins/`；
5. 创建 `Runtime` 单例（校验配置、装配客户端/服务/缓存/渲染器/白名单）；
6. 安装掉线监控；
7. `nonebot.run()`；关闭时 `Runtime.aclose()` 释放 HTTP/SQLite/浏览器。

`Runtime` 在 import 阶段创建，配置或资源有问题会在启动时立刻暴露；各功能初始化都用
try/except 包住，单个功能失败只关闭自己，不影响其他功能。

### 4.2 分层与优先级

- 插件层只做匹配与发送；业务逻辑在 `services/`；外部数据在 `adapters/`。
- 消息 matcher 优先级：
  - 上下文清理：`priority=9`
  - 卡战备、每日密码、直播订阅、制造利润、帮助、猪猪表情包、猪结婚、每日天尊挑战：`priority=10`
  - 群聊：`priority=50`
  - 全部 `block=True`
- `plugins/llm_chat.py` 的 `event_preprocessor` 把白名单群的人类消息写入聊天数据库。
- 聊天插件把 `/卡战备`、`/每日密码`、`/直播订阅`、`/制造利润`、`/帮助`、`/waifu`、
  `/每天日尊挑战`、`/每日天尊挑战`、`上下文清理` 识别为命令，不会交给 LLM。
- 娱乐功能（猪猪/猪结婚/天尊挑战）只认 `FUN_GROUPS`；不在白名单的群不会响应。

## 6. 各功能实现机制

### 6.1 卡战备

- 命令必须严格斜杠；地图+难度映射到接口 `lv`（`config/gates.json`）。
- 数据帝 V4 `jzv4_zb`，1 次资源/请求；按 `lv` 缓存 4h；同参数并发合并。
- 限流：每用户 2 次/分钟、每群 10 次/分钟；`DEBUG_GROUPS` 免限流。
- 卡片渲染失败或发图失败自动回退文字；图片只在发送成功后写缓存。
- 本地熔断 `ORZICE_DAILY_QUOTA=2000`。

### 6.2 群聊

- 触发：@、引用机器人消息、`CHAT_ALIASES` 别名、机器人回复后的 180s 跟进窗口。
- 跟进窗口内最多再回 3 次，间隔至少 20s；`CHAT_AMBIENT_ENABLED=false` 默认不主动接话。
- 群共享上下文存 `data/chat.sqlite3`；历史字符预算 6000，输入截断 2000，默认保留 7 天。
- 视觉输入：当前消息图片转 base64 传给模型；单张 8MB、最多 4 张。
- 回复拆成最多 3 条短消息，每条 1500 字；不使用 QQ 引用回复。
- 本地表情包通过 `send_meme(category)` 工具发送；同群 30s 冷却、10min 最多 5 张。
- 每日 token 预算 200000 是本地熔断，不是供应商账单上限；并发 3。
- 上下文清理仅 `SUPERUSERS`：`提取摘要` 成功后才删原始消息；`直接清理` 直接删。

### 6.3 每日密码

- 每天 UTC+8 00:15 预热（4399 在 0:06~0:10 才刷新），11:00 推送；11:00~12:00 补推。
- 同一天只向上游取一次；4399 失败换 eleven；同一天用备用源后不会因主源恢复而升级。
- 独立 `data/daily_password.sqlite3`；同群手动查询 5min 冷却；图片卡片失败回退文字。

### 6.4 直播订阅

- 全局订阅：任一群添加/删除，两个推送群同时生效。
- 180s 批量轮询 B站公开接口；必须浏览器 UA + Referer；批量参数 `uids[]=...`。
- 用 `live_time` 做场次去重；只推开播，不推下播；添加时正在直播会抑制当前场次。
- 卡片 JPEG 目标 350 KB；失败回退文字（文字始终带直播间链接）。

### 6.5 制造利润

- 数据帝 Pro `manufacturePro`，四个台固定 `l=3`；每台取 `price_hour` 最高 1 条。
- 一次刷新 4 次资源；12h 内存缓存；按需查询，无定时任务。
- 某台失败时卡片显示“数据获取失败”；渲染/发图失败回退文字。

### 6.6 帮助页

- 内容集中在 `services/help.py`；卡片和文字兜底共用同一份 `HELP_SECTIONS`。
- 9 个功能块：卡战备、每日密码、制造利润、直播订阅、群聊、管理员、猪猪表情包、猪结婚、每日天尊挑战。
- 前 8 个两列排列，最后一个横跨两列；三个娱乐功能用粉/珊瑚/青三种色条 + 浅色底纹。
- 卡片 1000×1450，JPEG 质量阶梯 86→80→72→64，目标 350 KB，硬上限 600 KB。
- 图片缓存 key `help-v3`，24h；渲染/发图失败回退文字版。

### 6.7 猪猪表情包

- 精确触发词：`猪`、`zhu`、`pig`、`🐖`、`🐷`；`猪猪`/`小猪`/`猪！` 不触发。
- 归一化：NFKC + casefold + 去首尾空白/零宽字符；`@bot 猪` 可触发。
- 目录 `assets/memes/pig` 启动扫描 100 张；只扫图片后缀，跳过超大文件；增删图需重启。
- 同群 5s 冷却，按 `group_id` 隔离；只回复触发群，不广播。
- 随机挑图，默认避开最近 8 张；发图失败只记日志。
- 受 `FUN_GROUPS` 控制；不在白名单的群不触发。

### 6.8 猪结婚

- 触发 `/waifu` 或 `/每天日尊挑战`；仅 `FUN_GROUPS` 群。
- 每天每群形成**互不重叠的配对**：
  - A 未配对：从“未配对、非机器人、非自己”的成员随机选 B；A-B 成对；
    拼图 A 左 B 右；回复文字 `你今天的老婆是B的群昵称`。
  - A 已配对：直接返回 B 和缓存图，不再随机。
  - B 发：返回 A，文字换成 A 的群昵称，图片沿用第一次那张（A 左 B 右）。
  - 其他成员不能选 A/B；未配对的人无对象时回复“群里没有其他群友可选”。
- 群昵称优先群名片，其次 QQ 昵称，最后 QQ 号；排除机器人/自己。
- 模板 `assets/memes/waifu/猪结婚.jpg`（1012×1024）；左块 (239,309)-(504,627)，
  右块 (534,346)-(817,623)；Pillow `ImageOps.fit` cover 填满；输出 JPEG ~100–160 KB。
- SQLite `data/waifu.sqlite3`：`waifu_pairs` 存图片，`waifu_members` 每人一行，
  主键 `(day, group_id, user_id)` 保证一人一天只能在一对里；只保留今天+昨天。
- 按群异步锁避免并发重复配对；重启后当天配对不丢。

### 6.9 每日天尊挑战

- 触发 `/每日天尊挑战`；仅 `FUN_GROUPS` 群；与 `/waifu` 独立（独立插件/服务/SQLite）。
- 素材：
  - 怪物 `assets/monsters` 71 张 PNG，512×512；
  - 武器 `assets/weapons` 14 张 PNG，64×64；
  - 背景 `assets/monster_background/MonsterBackground.jpeg`，1920×1080。
- 文件名 `序号、名称.png`，正则 `^\d+、\s*(.+)$` 提取名称；不符合格式跳过并 warning。
- 流程：查缓存 `(day, group_id, user_id)` → 未命中则随机怪物/武器 → 下载发送者头像
  → 生成 HTML → Playwright 截图 → JPEG 压缩 → 引用回复只发图片 → 写 SQLite。
- 页面 1600×900：今日天尊（头像+群昵称）/ 今日猎物（怪物）/ 今日武器；
  背景压暗、卡片深色半透明+金色描边+景深；武器 64×64 图标加圆形徽章底。
- JPEG 质量阶梯 90→84→78→72，目标 350 KB，硬上限 600 KB；实测约 100–160 KB。
- SQLite `data/daily_challenge.sqlite3`，主键 `(day, group_id, user_id)`，只保留今天+昨天；
  同一人当天重复查询同图；按“群+人”异步锁防并发重复生成。

### 6.10 掉线监控与上下文清理

- 掉线/被下线：写日志、推 webhook（若配置）；恢复后私聊 `ALERT_QQ`；首连不通知；

### 9.1 更新代码

```powershell
cd D:\Project\DeltaForceQQbot
```

## 11. 已知问题 / 风险

1. **QQ 账号被踢/登录失效**：第三方协议端在云服务器 IP 上风控概率高；需要扫码或密码回退；
   详见掉线指南。
2. **NapCat 重启可能要扫码/短信**：不要频繁重启；优先 WebUI 热操作。
3. **服务器与 GitHub 版本差**：部署前确认服务器 `.env`/代码；部署脚本默认保留 `.env`。
4. **数据帝是非官方第三方服务**：可能改字段/停服/限额；缓存都是内存态，重启会重新取数。
5. **制造利润官方数据版不用**：没有 Lv3 参数、价格与 Pro 不一致、平台标注“不准”。
6. **B站直播**：WAF 会拦默认 `python-httpx` UA（412）；已固定浏览器 UA；
   只推开播；轮询最坏约 3 分钟延迟；群主/SUPERUSERS 才能增删。
7. **每日密码免费源**：4399/eleven 非官方，可能改版/停服；同一天一旦用备用源，
   当天不会因主源恢复而升级。
8. **资源不入库**：换机/重装要重新上传 `assets/items`、`assets/memes`、`assets/monsters`、
   `assets/weapons`、`assets/monster_background`、`.env`、`data/`。
9. **图片体积**：每日密码卡 ~217 KB，帮助页 ~207 KB，制造台 ~84 KB，直播 ~58 KB，
   天尊挑战 ~100–160 KB；卡片渲染失败会回退文字（天尊挑战回退文字提示）。
10. **聊天成本**：`CHAT_DAILY_TOKEN_BUDGET=200000` 是本地熔断，不是供应商账单上限。
11. **上下文清理权限**：只能 `SUPERUSERS`，群主/管理员没有权限。
12. **帮助页是静态内容**：功能变化要改 `services/help.py`；图片缓存 key 目前 `help-v3`。
13. **`LLM_BASE_URL`**：服务器当前值不带 `/v1`，客户端固定拼 `/chat/completions`；
    官方文档推荐 `/v1`，改动前先验证。
14. **FUN_GROUPS 为空会关闭三个娱乐功能**：猪猪表情包、猪结婚、每日天尊挑战都不响应；
    新增群必须改 `.env` 并重启。
15. **猪结婚**：模板白块坐标硬编码在 `render/waifu_card.py`，换模板必须同步改坐标和尺寸；
    依赖 Pillow，部署不能 `--skip-deps`；A/B 共享同一张图（A 左 B 右）。
16. **每日天尊挑战**：素材文件名必须「序号、名称」；与 `/waifu` 独立，仅共用 `FUN_GROUPS`；
    截图 1600×900 JPEG；按“日期+群+人”缓存。
