# 每日天尊挑战（/每日天尊挑战）

> 适用：v0.9.0 之后新增的独立娱乐功能 ｜ 受 `FUN_GROUPS` 白名单控制
>
> 群友发 `/每日天尊挑战`，机器人随机抽一个怪物、一种武器，取发送者头像，
> 按「今日天尊 / 今日猎物 / 今日武器」三栏生成 HTML，用 Playwright 截图并压缩，
> 以 QQ 引用回复的形式只发图片。

## 1. 触发与白名单

| 命令 | 说明 |
| --- | --- |
| `/每日天尊挑战` | 支持全角斜杠；必须整条消息恰好是命令 |

只处理群消息，私聊无效；不依赖 `CHAT_ENABLED` / `CHAT_GROUPS`，
但**必须**在 `.env` 的 `FUN_GROUPS` 里列出该群，否则不会响应：

```dotenv
FUN_GROUPS=1071781482,1130331921
```

`FUN_GROUPS` 同时控制猪猪表情包、猪结婚和每日天尊挑战；为空时三个功能全部关闭。
三个功能的数据/缓存互相独立，本功能与 `/waifu` 没有任何交集。

## 2. 行为

1. 计算当天日期（UTC+8），先查缓存 `(日期, 群号, 群友QQ)`：
   - 命中：直接返回同一张图，不再随机/下载/渲染。
   - 未命中：随机抽怪物和武器，下载发送者头像，生成图片并写缓存。
2. 缓存一天有效；同一群友当天重复查询结果不变；不同群/不同人各自一份。
3. 成功回复只有图片（QQ 引用回复），不附带文字。
4. 图片包含发送者的群昵称；群名片为空时退回 QQ 昵称，再退回 QQ 号。
5. 渲染/头像失败时回简短文字提示，不写缓存；不影响其他功能。

## 3. 素材

| 素材 | 路径 | 数量/规格 |
| --- | --- | --- |
| 怪物图标 | `assets/monsters` | 71 张 PNG，512×512，透明背景 |
| 武器种类 | `assets/weapons` | 14 张 PNG，64×64，透明背景 |
| 背景图 | `assets/monster_background/MonsterBackground.jpeg` | 1920×1080 |
| 页面原型 | `assets/items/html_prototype/每日天尊挑战原型图.png` | 三栏布局说明 |

文件名格式为 `序号、名称.png`（例如 `27、灭尽龙.png`、`1、大剑.png`），
索引时只取「、」后面的名称；不符合格式的文件会跳过并记 warning。

## 4. 页面与压缩

模板：`deltaforce_bot/render/templates/daily_challenge.html.j2`，1600×900。

- 左栏：`今日天尊` + 发送者圆形头像 + 群昵称；
- 中栏：`今日猎物` + 怪物图标 + 怪物名称；
- 右栏：`今日武器` + 武器图标 + 武器名称；
- 背景压暗 + 暗角 + 渐变，卡片使用深色半透明底、金色描边、景深阴影；
- 截图 JPEG 质量阶梯 `90 → 84 → 78 → 72`，目标 `DAILY_CHALLENGE_IMAGE_MAX_KB=350`，
  硬上限 600 KB，超过则回退文字提示。

## 5. 配置

```dotenv
FUN_GROUPS=1071781482,1130331921
DAILY_CHALLENGE_ENABLED=true
DAILY_CHALLENGE_DB_PATH=data/daily_challenge.sqlite3
DAILY_CHALLENGE_MONSTER_DIR=assets/monsters
DAILY_CHALLENGE_WEAPON_DIR=assets/weapons
DAILY_CHALLENGE_BACKGROUND=assets/monster_background/MonsterBackground.jpeg
DAILY_CHALLENGE_KEEP_DAYS=2
DAILY_CHALLENGE_IMAGE_MAX_KB=350
DAILY_CHALLENGE_AVATAR_TIMEOUT=10
DAILY_CHALLENGE_AVATAR_MAX_BYTES=5242880
```

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `FUN_GROUPS` | 空 | 娱乐功能开放群；为空三个功能全部关闭 |
| `DAILY_CHALLENGE_ENABLED` | `true` | 功能开关 |
| `DAILY_CHALLENGE_DB_PATH` | `data/daily_challenge.sqlite3` | 每日缓存 SQLite |
| `DAILY_CHALLENGE_MONSTER_DIR` | `assets/monsters` | 怪物图库 |
| `DAILY_CHALLENGE_WEAPON_DIR` | `assets/weapons` | 武器图库 |
| `DAILY_CHALLENGE_BACKGROUND` | `assets/monster_background/MonsterBackground.jpeg` | 背景图 |
| `DAILY_CHALLENGE_KEEP_DAYS` | `2` | 只保留今天和昨天 |
| `DAILY_CHALLENGE_IMAGE_MAX_KB` | `350` | JPEG 压缩目标 |
| `DAILY_CHALLENGE_AVATAR_TIMEOUT` | `10` | 头像请求超时秒数 |
| `DAILY_CHALLENGE_AVATAR_MAX_BYTES` | `5242880` | 单张头像上限 |

改 `.env` 后需要重启 `deltaforce-bot`。

## 6. 存储

独立 SQLite：`data/daily_challenge.sqlite3`，不复用聊天/每日密码/猪结婚数据库。

```sql
CREATE TABLE daily_challenges (
    day TEXT NOT NULL,
    group_id INTEGER NOT NULL,
    user_id INTEGER NOT NULL,
    monster_name TEXT NOT NULL,
    weapon_name TEXT NOT NULL,
    image BLOB NOT NULL,
    created_at REAL NOT NULL,
    PRIMARY KEY (day, group_id, user_id)
);
```

图片直接存 BLOB（约 100–160 KB/张），启动和每天首次使用时清理旧日期。
重启后当天缓存仍然有效。

## 7. 部署

不需要新增 Python 依赖（复用 Playwright + Pillow 环境）。素材不在 Git 里，需要上传：

```powershell

scp -r .\assets\weapons root@39.106.135.148:/opt/deltaforce-qqbot/assets/

```

## 8. 验收

1. 在白名单群发 `/每日天尊挑战` → 引用回复一张三栏图，无文字。
2. 同一人当天再发 → 同一张图、同一怪物/武器。
3. 换一个人发 → 新的随机组合（可能碰巧相同）。
4. 在非白名单群发 → 无响应。
5. 头像/渲染失败 → 简短文字提示，不写缓存。

## 10. 常见问题

**发命令没反应？**
检查 `FUN_GROUPS` 是否包含该群，以及启动日志有没有“每日天尊挑战已启用”。

**图片里怪物/武器没加载？**
确认 `assets/monsters`、`assets/weapons`、`assets/monster_background` 已上传，
文件名符合 `序号、名称`，且服务用户可读。

**同一人再发为什么还是同一个？**
这是按天的缓存，次日 0 点后才会重新随机。

**和 `/waifu` 有交集吗？**
没有。独立插件、独立服务、独立 SQLite；只共用同一个 `FUN_GROUPS` 白名单开关。
