# 猪猪表情包

> 适用：v0.9.0 之后新增的独立功能 ｜ 不依赖聊天开关或群白名单
>
> 群友发送固定触发词时，机器人从 `assets/memes/pig` 随机回一张猪表情包；
> 只回复触发消息所在的群，同群 5 秒冷却。

## 1. 触发规则

消息文本（去掉首尾空白、统一全角/大小写后）**恰好**等于以下之一才会触发：

| 触发词 | 说明 |
| --- | --- |
| `猪` | 中文单字 |
| `zhu` | 不区分大小写（`Zhu`/`ZHU` 都行） |
| `pig` | 不区分大小写 |
| `🐖` | 猪 emoji |
| `🐷` | 猪头 emoji |

不会触发的情况：

- `猪猪`、`小猪`、`猪！`、`piggy` 等包含触发词的更长文本；
- 斜杠命令（`/卡战备` 等）由更高优先级插件处理；
- 私聊消息（只处理群消息）。

`@机器人 猪` 会触发：OneBot 的纯文本会去掉 @ 段，剩下的 `" 猪"` 去空白后正好命中。

## 2. 行为

- **按群隔离**：`matcher.send` 只在收到消息的群回复，不会向 `CHAT_GROUPS` 或其他群广播；
  冷却也按 `group_id` 分别记录，A 群触发不影响 B 群。
- **同群 5 秒冷却**：冷却内的重复触发静默忽略，不回复文字，避免刷屏。
- **随机 + 避免连发**：默认避开最近发过的 8 张；目录图少时会自动放宽。
- **独立于聊天**：不需要 `CHAT_ENABLED=true`，也不受 `CHAT_GROUPS` 限制；
  但必须在 `.env` 的 `FUN_GROUPS` 白名单内（为空则功能关闭）；
  命中后直接拦截，不会再交给 LLM 聊天。
- **失败静默**：目录为空、读取失败或发图失败只写日志，不刷屏。

## 3. 配置

```dotenv
FUN_GROUPS=1071781482,1130331921
PIG_MEME_ENABLED=true
PIG_MEME_DIR=assets/memes/pig
PIG_MEME_COOLDOWN=5
PIG_MEME_MAX_BYTES=8388608
PIG_MEME_RECENT_EXCLUDE=8
```

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `FUN_GROUPS` | 空 | 娱乐功能开放群；为空时猪猪表情包关闭 |
| `PIG_MEME_ENABLED` | `true` | 功能开关 |
| `PIG_MEME_DIR` | `assets/memes/pig` | 图片目录；相对路径基于项目根目录 |
| `PIG_MEME_COOLDOWN` | `5` | 同群冷却秒数；`0` 表示关闭冷却 |
| `PIG_MEME_MAX_BYTES` | `8388608` | 单张上限；启动扫描时跳过超大文件 |
| `PIG_MEME_RECENT_EXCLUDE` | `8` | 避开最近 N 张；`0` 表示不限制 |

改 `.env` 后需要重启 `deltaforce-bot`。

## 4. 图片资源

当前素材来自 [PigHub](https://pighub.top/) 的公开图片接口 `GET /api/images?sort=2`：

- 取最新 100 张**静态图**，跳过 GIF 和动图 WebP/APNG；
- 按内容 SHA-256 去重；
- 实际格式以文件头为准：91 张 WebP + 9 张 JPEG，共约 3.4 MB；
- 文件名 `pighub_{id}_{标题}.{扩展名}`，方便追溯来源。

本地开发路径与服务器运行路径：

| 环境 | 路径 |
| --- | --- |
| 本地仓库（运行目录） | `assets/memes/pig` |
| 本地素材仓库（源） | `assets/astrbot-deepseek-meme-pack-main/astrbot-deepseek-meme-pack-main/memes/pig` |
| 服务器 | `/opt/deltaforce-qqbot/assets/memes/pig` |

图片被 `.gitignore` 排除，不在 Git 里；换机/重装要单独上传。

## 5. 部署

代码走常规部署即可（不需要新依赖）：

```powershell
.\.venv\Scripts\python.exe .\scripts\deploy_server.py --host 39.106.135.148 --user root `
  --skip-assets --skip-deps
```

图片目录需要单独同步。`deploy_server.py --put` 只支持单文件，目录建议用 `scp`/`tar`：

```powershell
scp -r .\assets\memes\pig root@39.106.135.148:/opt/deltaforce-qqbot/assets/memes/
```

或在服务器上直接确认：

```bash
ls -1 /opt/deltaforce-qqbot/assets/memes/pig | wc -l   # 应为 100
```

权限保持目录 `755`、文件 `644`，属主 `root:root` 或服务用户可读即可。

重启并看日志：

```bash
systemctl restart deltaforce-bot
journalctl -u deltaforce-bot -n 60 --no-pager | grep -E '猪猪表情包|PIG_MEME'
```

正常应出现：

```
猪猪表情包索引完成：100 张（/opt/deltaforce-qqbot/assets/memes/pig）
猪猪表情包已启用：100 张，同群冷却 5 秒（...）
```

目录不存在或为空时会出现 warning，但不会影响卡战备、聊天等其他功能。

## 6. 验收

1. 在群里发 `猪` → 回一张随机猪图；
2. 5 秒内再发 `猪` → 不回复（冷却）；
3. 5 秒后发 `zhu` / `pig` / `🐖` / `🐷` → 各回一张；
4. 在另一个群发 `猪` → 立即可回（冷却按群隔离）；
5. 发 `猪猪`、`小猪`、`猪！` → 不触发；
6. 关闭聊天（`CHAT_ENABLED=false`）后发 `猪` → 仍能回图（功能独立）。

## 8. 常见问题

**发 `猪` 没反应？**
先看启动日志有没有“猪猪表情包索引完成”。没有的话检查 `PIG_MEME_ENABLED`、`PIG_MEME_DIR`
和目录权限；日志出现“目录不存在/为空”说明图片没上传或路径不对。

**新增图片后没生效？**
目录在启动时扫描，重启 `deltaforce-bot` 后才会索引新图。

**会不会和聊天抢消息？**
会拦截，这是预期行为：五个触发词由本功能独占，不会再交给 LLM；但只在触发群里回复，
不会影响其他群。

**WebP 能发吗？**
可以，现有聊天表情包本身就有大量 WebP；单张上限由 `PIG_MEME_MAX_BYTES` 控制。
